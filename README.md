# fzv

**The file viewer for agent-driven development.**

CLIやデスクトップのcoding agentで開発し、プロジェクトの中身はブラウザで確認する。
fzvは、ファイル閲覧のためにIDEを起動する手間を省く、読み取り専用のローカルWebアプリです。
名前は **fuzzy viewer** を表す3文字の `fzv`。

ファイル名・パスのfuzzy search、複数ファイルのタブ表示、PDF・HTML・画像・テキストの
プレビューに対応します。タブの順序と選択状態はプロジェクトごとに保存します。

## 動作環境

- Node.js 24以降とnpm
- Chrome、Edge、Firefox、Safariなどの現行デスクトップブラウザ
- PDF表示はブラウザ内蔵ビューアを使用します。表示できない場合は「Open separately」から開けます。

実行時の外部npmパッケージ依存はありません。UIを含むビルド済みファイルを配布し、
利用者の環境でTypeScriptやViteを実行する必要はありません。

## 起動

**npmレジストリにはまだ公開していません。** 公開後の利用方法は以下です。

```bash
npx fzv@latest
npx fzv@latest --root ~/projects/example
npx fzv@latest --root . --port 8001
```

現在のソースから使う場合:

```bash
npm ci
npm run build
node dist/server/cli.js --root /path/to/project
```

表示されたURLをブラウザで開きます。既定値は `http://127.0.0.1:8000/` です。
`Ctrl+C` で終了します。

| オプション        | 既定値                       | 説明                                       |
| ----------------- | ---------------------------- | ------------------------------------------ |
| `--root PATH`     | 起動時のカレントディレクトリ | 閲覧対象のディレクトリ                     |
| `--host HOST`     | `127.0.0.1`                  | 待受アドレス                               |
| `--port PORT`     | `8000`                       | ポート番号。`0` は空きポートを自動割り当て |
| `-h`, `--help`    | —                            | ヘルプを表示                               |
| `-v`, `--version` | —                            | バージョンを表示                           |

ポートが使用中なら `--port 8001` などを指定します。

## 使い方

検索結果をクリックするか、検索欄で `↑` / `↓` と `Enter` を使うとファイルが開きます。
`/` で検索ポップアップを開くと、ルート直下のディレクトリとファイルを表示します。
ディレクトリ名も検索でき、選択すると検索欄にそのパスを入力して直下の項目を表示します。
ファイルを選ぶとポップアップを閉じてタブを開きます。
スペースで区切った検索語はすべてパスに一致するものを探します。
英字の大文字を含む語は大文字・小文字を区別します。

| 操作                       | 方法                                                  |
| -------------------------- | ----------------------------------------------------- |
| 検索欄を開く               | `/`。入力欄への入力中は発動しません                   |
| 検索欄を閉じる             | `Escape` またはポップアップの外をクリック             |
| リンク・ボタンへジャンプ   | `f` でヒントを表示し、ラベルの文字を入力              |
| ジャンプを中止             | `Escape`。`Backspace` で入力したヒントを1文字戻す     |
| 左・下・上・右へスクロール | `h` / `j` / `k` / `l`                                 |
| 先頭・末尾へスクロール     | `gg` / `G`                                            |
| ライト・ダークの切替       | 上部のテーマボタン                                    |
| 次・前のタブ               | `Alt+J` / `Alt+K`                                     |
| タブの移動                 | タブにフォーカスした状態で `←` / `→` / `Home` / `End` |
| タブを閉じる               | タブの `×`、またはタブにフォーカスして `Delete`       |
| 選択中ファイルの再取得     | `r` またはツールバーの「Reload」                      |
| 表示モードの切替           | Markdown・HTML表示中に「Viewer」/「Source」           |
| ファイルの追加・削除を反映 | 検索ポップアップ内の「Refresh」                       |
| 画像の拡大・縮小           | 画像ツールバー、または `Ctrl` を押しながらホイール    |
| 画像の移動                 | 拡大した画像をドラッグ                                |
| 画像を表示領域に合わせる   | 「Fit」                                               |

`Ctrl+Tab` / `Ctrl+Shift+Tab` もイベントがアプリに届く場合に対応します。
通常はブラウザ自身が使用するため、`Alt+J` / `Alt+K` またはタブの矢印キーを利用してください。
入力欄や編集可能なテキストでは、これらの単独キーを通常の文字入力として扱います。
リンクヒントは画面内で見えている操作対象だけに表示します。Markdownのリンク、タブ、
ツールバーボタンもキーボードで操作できます。
HTMLプレビュー内でもジャンプ・スクロール・`/`検索・`r`再読込に対応します。
ブラウザ内蔵PDFビューア内にフォーカスがある場合、キー操作はブラウザの実装に依存します。

テーマは初回にOS・ブラウザの設定に従い、手動で選んだ設定をlocalStorageに保存します。
UI・Markdown・ソースの配色が連動します。HTML内の独自の配色や画像・PDFの内容は保持します。

タブを切り替えてもプレビューは保持されます。ブラウザを再読み込みした際は、
タブを復元し、ファイル内容をディスクから読み直します。
状態の保存先はブラウザのlocalStorageで、正規化したルートの識別子ごとに分かれます。
ブラウザのorigin（ホスト・ポート）が変わった場合は、保存状態も別になります。

## プレビュー対象と除外規則

- PDF: `.pdf`
- HTML: `.html`, `.htm`。相対パスの画像・CSS・フォントを同じルート内から配信
- 画像: `.png`, `.jpg`, `.jpeg`, `.gif`, `.webp`, `.svg`, `.avif`, `.bmp`, `.ico`
- テキスト: `.txt`, `.md`, `.json`, `.csv`, `.ts`, `.js`, `.py`, `.rs`, `.go`, `.tex`, `.yaml` など、および `Makefile`, `Dockerfile`, `LICENSE`, `NOTICE` など

テキストはUTF-8として表示します。HTML・Markdownは「Viewer」を初期表示にし、
「Source」で行番号付きの原文に切り替えられます。モードはタブごとに保持し、`r`で再取得しても維持します。
TypeScript・JavaScript・Python・JSONなど、その他のテキストは「Source」のみで開きます。
ShikiのTextMate文法とVS Code Light+・Dark+テーマでシンタックスハイライトします。
文法のない形式や512 Ki文字を超えるファイルは、原文をそのまま表示します。
Markdown内の相対リンクと画像は、プロジェクトルートの検証を通るアセット経由で読み込みます。
スクリプトや危険なHTML属性は除去し、リンクは別タブで開きます。外部画像は表示しません。
UIのアイコンはVS CodeのCodiconsを使用します。タブと検索ポップアップにはVS Code本体のCSSと
Light Modern・Dark Modernの配色定義を使用し、フォント・文法・テーマをパッケージに同梱します。
編集、Office文書の変換は初版には含めません。

1ファイルあたり **20 MiB以下**。`.`で始まるファイル・ディレクトリと、
`node_modules`・`__pycache__` 配下は一覧にも直接取得にも含めません。
`.gitignore` の解釈は初版では行いません。

ディレクトリのシンボリックリンクは探索しません。ファイルのシンボリックリンクは、
実体が同じルート内の公開対象で、プレビュー形式が一致するものだけを許可します。
ルート外、隠しファイル、除外対象を指すリンクは配信しません。

HTMLはsandboxとCSPで表示し、親アプリやlocalStorageへのアクセスを制限します。
インラインJavaScriptは動作しますが、外部JavaScript・API通信・入れ子のiframeは制限します。
任意のWebアプリの完全再現には対応しません。HTML内の外部画像・CSS等は読み込めるため、
それらのURLへの通信は発生します。アプリ本体はCDNや外部サービスを使用しません。

## ネットワーク公開

既定では起動したマシンの `127.0.0.1` だけで待ち受けます。
LAN上の他の端末から使う場合は明示的に指定します。

```bash
node dist/server/cli.js --root /path/to/project --host 0.0.0.0 --port 8001
```

他の端末では `http://<起動したマシンのIP>:8001/` を開きます。
`--host 0.0.0.0` の場合、起動時にループバックと各インターフェースのIPv4アドレスを
URLとして一覧表示します。LANやTailscale等のVPNアドレスも含みます。
各端末からの到達可否はネットワーク経路やファイアウォールの設定に依存します。
認証やTLSは備えていないため、アクセスできる端末は公開対象のファイルを閲覧できます。
ネットワーク公開は信頼できる範囲で使用してください。

## 開発

```bash
npm ci
npm run dev
```

`npm run dev` は全体をビルドしてローカルサーバーを起動します。
UIのホットリロードが必要な場合は、既定の8000番でサーバーを動かしたまま、
別のターミナルで `npm run dev:ui` を実行し、Viteが表示するURLを開きます。

```bash
npm run check          # TypeScriptの型検査
npm test               # ビルド、単体・HTTP・配布パッケージのテスト
npm run test:browser   # Chromeで実際のUIを確認
```

ブラウザテストは既定でインストール済みGoogle Chromeを使用します。
Chromeがない環境では `npx playwright install chrome` でテスト用ブラウザを準備できます。

```text
src/server/    CLI、HTTP配信、ファイル探索・パス検証
src/client/    画面、検索、タブ状態、プレビュー、CSS
src/shared.ts  APIの型、製品名、バージョン、サイズ上限
test/          サーバー・検索・状態保存・配布・ブラウザのテスト
dist/          npmに同梱するビルド済みファイル（Git管理対象外）
```

## 配布パッケージの作成

```bash
npm pack
npx --yes --package ./fzv-0.1.0.tgz fzv --root /path/to/project
```

`npm pack` の前に自動でビルドします。配布物は `dist/` とREADME、ライセンス、
帰属表示に限定し、閲覧対象プロジェクトや開発依存は同梱しません。
公開先アカウントやバージョンを確認したうえで、npmへの公開は別途行います。
