[English](https://github.com/iiii1224/fzv/blob/main/README.md) | 日本語

コーディングエージェントに作らせたファイルを、IDE を開かずにブラウザで探して読むための読み取り専用ビューアです。PDF、HTML、画像、ソースコード、Office 文書を、同じタブと分割画面で切り替えながら確認できます。

```console
$ npx --yes @aaa_iii/fzv@latest --watch

  fzv 0.2.0
  Project  ~/dev/fzv
  Viewer   http://127.0.0.1:29814/
  Office   ibisOffice (~/.local/bin/ibisOffice)

  Press Ctrl+C to stop.
```

表示された URL をブラウザで開き、`/` でファイルを検索します。

## 特徴

ターミナルでエージェントに指示を出しながら、生成された成果物だけを横で確かめる、という使い方を想定しています。

- **`npx` 一行で起動**: 実行時に依存パッケージを取得しません。UI、PDF.js、フォントは配布パッケージに含まれており、インストール時のビルドもありません。
- **形式が違っても操作は同じ**: PDF も Markdown も画像も、同じタブ、分割、キー操作で扱います。
- **キーボードで完結**: `/` であいまい検索、`hjkl` でスクロール、`f` で画面上のリンクやボタンへジャンプします。
- **ファイルを書き換えない**: 書き込み機能はなく、プロジェクトのルートより外へのアクセスは拒否します。

**できないこと**: ファイルの編集、ファイル内容の全文検索、`.gitignore` の解釈、旧形式の Office 文書（`.doc`、`.xls`、`.ppt`）の表示、認証付きの公開。編集や全文検索には、エディタや `rg` を併用してください。

## 必要なもの

- Node.js 24 以降
- 現行のデスクトップブラウザ
- Office 文書を表示する場合: [ibisOffice](https://github.com/ibisjp/ibis-office) または [LibreOffice](https://www.libreoffice.org/)

## 起動する

```bash
# カレントディレクトリを開く
npx --yes @aaa_iii/fzv@latest

# ファイルの変更を検知して、検索対象と開いているタブを更新する
npx --yes @aaa_iii/fzv@latest --watch

# 別のディレクトリを開く
npx --yes @aaa_iii/fzv@latest --root ~/projects/example
```

`Ctrl+C` で終了します。

ポートは、プロジェクトのパスから 20000〜29999 番の中で決まります。同じプロジェクトなら毎回同じ URL になるので、ブラウザに保存されたタブ、分割、テーマが次の起動時にも戻ります。そのポートが使用中のときは空いているポートで起動し、ターミナルに警告を出します。この場合は URL が変わるため、前回の状態は戻りません。

## 使い方

### ファイルを探す

`/` を押すか「Find a file」をクリックすると検索が開きます。何も入力していないときは、ルート直下のファイルとディレクトリが並びます。ディレクトリを選ぶとその中に移動し、文字を入力するとパスをあいまい検索します。スペースで区切った語は、すべて含むパスだけに絞り込みます。

ファイル一覧は検索を開くたびに裏で読み直すため、ページを開いた後に作られたファイルも見つかります。読み直している間も、直前の一覧でそのまま検索できます。

隠しファイルと隠しディレクトリ、`node_modules`、`__pycache__` は一覧に出ません。

### タブと分割

ファイルはタブで開きます。タブはドラッグして並べ替えたり、上下左右にドロップして画面を分割したりできます。`Ctrl` を押しながら（macOS では `Option`）ドラッグすると、移動ではなく複製になります。分割は最大 32 個で、境界をドラッグして大きさを変えられます。

開いているタブ、分割の配置、表示モードはブラウザに保存され、再読み込みしても戻ります。

### プレビューできる形式

| 形式     | 拡張子                                                                                            | 表示                                           |
| -------- | ------------------------------------------------------------------------------------------------- | ---------------------------------------------- |
| PDF      | `.pdf`                                                                                            | 文字選択、文書内検索、ズーム                   |
| HTML     | `.html` `.htm`                                                                                    | sandbox 内で描画。ソース表示に切り替え可能     |
| Markdown | `.md`                                                                                             | 整形表示。ソース表示に切り替え可能             |
| 画像     | `.png` `.jpg` `.jpeg` `.gif` `.webp` `.avif` `.bmp` `.svg` `.ico`                                 | 拡大、縮小、移動                               |
| Office   | `.docx` `.xlsx` `.pptx`                                                                           | PDF に変換して表示                             |
| テキスト | `.ts` `.js` `.py` `.rs` `.go` `.json` `.yaml` `.toml` `.tex` `.csv` など、`Makefile` `Dockerfile` | 行番号とシンタックスハイライト付きのソース表示 |

1 ファイルあたり 20 MiB までです。表示中のファイルは「Download」から元の形式で保存できます。

### 変更の確認

プロジェクトが git リポジトリ内にあり、`PATH` に `git` がある場合、未コミットの変更があるテキストファイルのツールバーに「Open Changes」ボタンが表示されます。VS Code と同じ形式の diff を左右に並べて開き、変更された行と、その中で変わった文字をハイライトします。作業ツリーの変更は index とディスク上のファイルを、ステージ済みの変更だけがある場合は `HEAD` と index を比較します。

diff のツールバーでは、変更間の移動（`]c` / `[c` でも可）、インライン表示への切り替え、変更のない範囲の折りたたみ、行頭・行末の空白の差分を表示するかどうかの切り替えができます。空白の差分は既定で表示します。fzv は git を読み取るだけで、ステージやコミット、index のロック取得は行いません。

## キー操作

| キー                     | 操作                                         |
| ------------------------ | -------------------------------------------- |
| `/`                      | ファイル検索を開く                           |
| `?`                      | キー操作の一覧を表示                         |
| `f`                      | リンクやボタンにラベルを出し、入力でジャンプ |
| `h` `j` `k` `l`          | プレビューをスクロール                       |
| `gg` / `G`               | 先頭 / 末尾へ移動                            |
| `r`                      | 表示中のファイルを読み直す                   |
| `Alt+J` / `Alt+K`        | 同じ分割内で次 / 前のタブへ                  |
| `Ctrl/Cmd+\`             | 右に分割                                     |
| `Ctrl/Cmd+Shift+\`       | 下に分割                                     |
| `Ctrl/Cmd+1`〜`9`        | 分割領域にフォーカス                         |
| `Ctrl/Cmd+F`             | PDF 内を検索                                 |
| `Ctrl/Cmd` + `+` `-` `0` | 画像と PDF のズーム（`0` で画面に合わせる）  |
| `]c` / `[c`              | diff で次 / 前の変更へ                       |
| `Escape`                 | 検索、ヘルプ、ラベル表示を閉じる             |

入力欄では文字入力が優先されます。ブラウザが予約しているショートカットは、ブラウザの動作が優先されます。

## Office 文書のプレビュー

`.docx`、`.xlsx`、`.pptx` は、手元の ibisOffice か LibreOffice で PDF に変換してから表示します。fzv は起動時に `PATH` から `ibisOffice`、`soffice`、`libreoffice` の順で探し、macOS では `/Applications` 内のアプリも探します。見つかった変換ソフトは起動メッセージの `Office` 行に表示されます。

見つからない場所にある場合は、`--office-converter` でパスを指定します。

```bash
npx --yes @aaa_iii/fzv@latest --office-converter ~/Applications/ibisOffice-0.8.4-Linux.AppImage
```

実行ファイル名が `soffice` または `libreoffice` で始まる場合は LibreOffice として、それ以外は ibisOffice として呼び出します。変換結果はファイルの内容ごとにキャッシュされ、内容が変わると変換し直します。

## オプション

| オプション                | 既定値                     | 説明                                                                 |
| ------------------------- | -------------------------- | -------------------------------------------------------------------- |
| `--root PATH`             | カレントディレクトリ       | 開くプロジェクトのルート                                             |
| `--host HOST`             | `127.0.0.1`                | 待ち受けるアドレス                                                   |
| `--port PORT`             | プロジェクトのパスから決定 | `0` で空きポート。明示したポートが使用中なら起動しない               |
| `--watch`                 | 無効                       | ファイルの変更を検知して、検索対象と開いているタブを更新             |
| `--allow-html-network`    | 無効                       | HTML プレビューに外部スクリプトの読み込みとネットワーク通信を許可    |
| `--office-converter PATH` | `PATH` から自動検出        | Office 文書の変換に使う ibisOffice または LibreOffice の実行ファイル |
| `-h`, `--help`            |                            | ヘルプを表示                                                         |
| `-v`, `--version`         |                            | バージョンを表示                                                     |

## セキュリティ

既定では `127.0.0.1` だけで待ち受け、このマシンからしか開けません。LAN 内の別の端末から開くには、待ち受けアドレスを明示します。

```bash
npx --yes @aaa_iii/fzv@latest --host 0.0.0.0 --port 8000
```

**注意**: 認証も TLS もありません。接続できる人は誰でも、プロジェクト内の表示対象ファイルを読めます。信頼できるネットワークでだけ使ってください。

- サーバーは GET と HEAD だけを受け付け、別オリジンからの API リクエストを拒否します。
- HTML プレビューは sandbox 内で動き、fzv 本体のページやストレージには触れません。インラインスクリプトは動きますが、外部スクリプトと API 通信は既定で遮断します。画像、CSS、フォントは読み込まれる場合があります。`--allow-html-network` は、中身を信頼できる HTML にだけ使ってください。
- Office 文書は、検証したファイルの内容を一時ディレクトリにコピーしてから変換ソフトに渡します。変換ソフトがプロジェクトのパスを直接読むことはありません。一時ディレクトリは終了時に削除します。

## ソースから動かす

```bash
npm ci
npm run build
node dist/server/cli.js --watch
```

UI を変更しながら確認するときは、サーバーを起動したまま別のターミナルで `npm run dev:ui` を実行し、Vite が表示する URL を開きます。テストは `npm test` と `npm run test:browser` です。
